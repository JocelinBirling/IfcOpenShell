# BonsaiViewer22 - Keybindings

## Introduction
The main functions of the viewer must have keyboard shortcuts.
A default list of shortcuts is provided with the software. Each user can change them in the Settings.
The shortcuts can be exported and imported, to deploy the same configuration on a fleet of PCs, to uniformise the shortcuts across Qwerty and Azerty keyboards, and to move the configuration when the software version or the PC changes.

## Specification

### Default Shortcuts
- Every main function of the viewer has a shortcut.
- A default list of shortcuts is provided with the software.
- The editor offers a reset of a shortcut (or of all shortcuts) to its default value.

### Shortcut Editor
In the Settings, the shortcut editor offers:
- The list of the functions with their current shortcut.
- Click on a shortcut, then type the new key combination to record it.
- A search box and a filter on the function list.
- A conflict detection: a combination already used by another function triggers a warning.

### Export/Import
- The export saves the keybindings only, in a file.
- The shortcut is stored as typed: the file is tied to one keyboard layout (one export for Qwerty, one export for Azerty).
- The import replaces entirely the current keybindings with the ones of the file.

## Open Subject
The default list of shortcuts (which function, which key) needs to be defined.
